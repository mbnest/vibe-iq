# VibeIQ

Encode an organization's SDLC golden paths once, centrally, as a spec-driven pipeline of agents with real human gates — so every business vertical inherits them automatically instead of re-learning how to invoke every other platform team's tooling. The platform's value is orchestration and composition, not reimplementation.

**This repository currently holds design documentation only** — the output of an extended pre-planning conversation. No implementation yet.

## Start here

→ **[`docs/overview.md`](docs/overview.md)** — the whole idea in one read.

→ **[`docs/product-vision.md`](docs/product-vision.md)** — the executive "so what": per-feature business value and suggested build order.

→ [`docs/`](docs/) — the documentation map: architecture, per-agent specs, policies, decisions, and the working notes behind them.

## Status

Pre-planning. Every agent assignment, autonomy tier, and decision is a current working position to challenge, not a commitment. The named top blocker is the `spec.md` schema — see [`docs/decisions/log.md`](docs/decisions/log.md).
